# PrivateCard Backup Keeper 1.1.0

## Added

- **Backup to flash drive** button.
- System picker for selecting `Documents` on removable storage.
- One-way synchronization of internal `Documents/*.pc` to the selected USB directory.
- SHA-256 and size verification for both new and existing destination files.
- Temporary `.part` write followed by re-read verification and rename.
- Conflict protection: same-name files with different contents are never overwritten.
- Persistent SAF permissions for the automatic source and SD-card folders.

## Important installation note

Version 1.0.0 was signed with a temporary key that was not retained. Android therefore cannot accept 1.1.0 as an in-place update. Stop and uninstall 1.0.0, install 1.1.0, then select the source and SD-card folders again and press **Start monitoring**.

Files in phone `Documents`, the PrivateCard application directory, the SD card and the USB flash drive are not part of this app's private data and are not deleted by uninstalling Backup Keeper.
